# Product Language

Reserve copy is:

- concise
- calm
- direct
- premium
- human
- specific

Avoid:

- AI assistant clichés
- influencer language
- excessive exclamation
- motivational filler
- technical infrastructure errors
- inflated promises
- childish gamification
- vague buttons such as Continue when a more precise action exists

Actions should describe the consequence:

- Build My Protocol
- Review the Week
- Adjust Today
- Save and Exit
- Apply This Change
