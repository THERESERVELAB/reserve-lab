# Responsive and Mobile

Validate every major screen at:

- 1440 × 1000
- 1280 × 900
- 820 × 1180
- 430 × 932
- 390 × 844
- 375 × 812

Mobile is not a collapsed desktop layout.

Evaluate:

- safe areas
- thumb reach
- minimum touch targets
- sticky actions
- bottom-sheet opportunities
- keyboard behavior
- scroll continuity
- text wrapping
- overflow
- visual priority
- one-handed use
- modal escape paths
- loading-state stability

Do not shrink dense desktop layouts until they technically fit.
Recompose them for mobile.
