# Prohibited Patterns

Reject:

- generic SaaS dashboard composition
- walls of identical cards
- pill and chip clouds
- tiny uppercase labels everywhere
- random glassmorphism
- decorative gradients without meaning
- rainbow status systems
- unnecessary icons
- every panel using the same radius and weight
- equal hierarchy across all modules
- oversized empty hero areas with weak utility
- dense forms presented all at once
- desktop-first layouts squeezed onto mobile
- fabricated health or performance metrics
- generic AI-generated product copy
- animation that hides synchronization defects
