# Motion

Motion should communicate:

- location
- state change
- successful completion
- hierarchy
- continuity

Motion must never exist only to decorate the screen.

Requirements:

- restrained durations
- consistent easing
- no animation that delays a primary action
- no transition that traps content in an intermediate state
- support reduced motion
- loading transitions must preserve layout stability
- success states should feel confident rather than celebratory or childish
